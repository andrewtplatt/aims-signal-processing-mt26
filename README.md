# AIMS Signal Processing — MT26

Code and lab exercises for the **Signal Processing** course at the University of Oxford's AIMS CDT, Michaelmas Term 2026.

Topics include graph signal processing, graph neural networks, and Gaussian processes on graphs.

## Setup

Dependencies are managed using [uv](https://docs.astral.sh/uv/). To install:

```bash
uv sync
```

## Contents

- `signal-processing.py` — Signal processing examples.
- `graph-signal-processing.py` — Graph signal processing examples.
- `AIMS_CDT_SP_Lab3.ipynb` — Graph neural networks and node classification.
- `AIMS_CDT_SP_Lab4.ipynb` — Gaussian processes on graphs.
